YOKAI OS — Dashboard v0.1

1. Rozpakuj archiwum.
2. Skopiuj folder "src" do:
   C:\Users\Emil1\Documents\yokai-os\frontend
   i zaakceptuj nadpisanie plików.

3. W terminalu VS Code:

   cd $HOME\Documents\yokai-os\frontend
   npm install lucide-react
   npm run dev

4. Otwórz:
   http://localhost:3000

5. Gdy wszystko działa:

   cd $HOME\Documents\yokai-os
   git add .
   git commit -m "Dashboard v0.1"
   git push
